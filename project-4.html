نبذة عن المشروعAbout the Project

نظام تبويبات تفاعلي يتيح عرض وإخفاء المحتوى بتأثيرات حركية سلسة (fade + slide). أربعة أقسام: تصاميم متحركة، إحصائيات مع أشرطة تقدم متحركة، معرض صور مصغّر، وشبكة أيقونات إيموجي مع تأثيرات hover. يعمل كله بجافا سكريبت نقي وسي إس إس بدون مكتبات.

An interactive tab system that shows and hides content with smooth animation effects (fade + slide). Four sections: animated designs, stats with animated progress bars, mini image gallery, and emoji icon grid with hover effects. All powered by pure JavaScript and CSS with no libraries.

  • تبديل تبويبات بتأثير fade+slide
  • Tab switching with fade+slide effect
  • أشرطة تقدم متحركة عند الظهور
  • Animated progress bars on reveal
  • أشكال هندسية نابضة (pulse)
  • Pulsing geometric shapes
  • معرض صور شبكي بتأثير zoom
  • Image gallery grid with zoom effect
  • أيقونات إيموجي مع hover effects
  • Emoji icons with hover effects
  • كود نقي بدون أي مكتبات خارجية
  • Pure code with no external libraries
