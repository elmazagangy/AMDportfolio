About the Project نبذة عن المشروع

Transformed Excel and Google Sheets into an interactive web tool for search, addition, and various calculations. Supports direct input, dynamic search, and a familiar spreadsheet interface that's faster and more interactive.

حوّلت ملفات Excel وGoogle Sheets إلى أداة ويب تفاعلية للبحث والجمع والحسابات المختلفة. يدعم الإدخال المباشر والبحث الديناميكي، مع واجهة تشبه جداول البيانات لكنها أسرع وأكثر تفاعلية.

Features المميزات

  • Editable data grid with add row support
  • جدول بيانات قابل للتعديل مع دعم إضافة صفوف
  • Real-time calculation (Sum, Average, Max, Min)
  • حساب فوري (مجموع، متوسط، أكبر، أصغر)
  • Dynamic search across all values
  • بحث ديناميكي في جميع القيم
  • Data persists via localStorage
  • البيانات تبقى محفوظة عبر localStorage
  • Tabbed interface (Input/Calc/Search)
  • واجهة بعلامات تبويب (إدخال/حساب/بحث)
  • RTL support for Arabic
  • دعم RTL للعربية
