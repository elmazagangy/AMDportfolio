About the Projectنبذة عن المشروع

A complete authentication system powered by InsForge backend. Features email/password registration, 6-digit OTP verification, Google & GitHub OAuth, password reset flow, and session management — all with a bilingual (AR/EN) responsive interface.

نظام تحقق كامل يعمل بواسطة InsForge. يشمل التسجيل بالبريد وكلمة المرور، التحقق برمز OTP مكون من 6 أرقام، الدخول الموحد عبر Google و GitHub، استعادة كلمة المرور، وإدارة الجلسات — كل ذلك بواجهة ثنائية اللغة متجاوبة.

  • Email/password registration with validation
  • تسجيل بالبريد وكلمة المرور مع التحقق
  • 6-digit OTP email verification
  • التحقق برمز OTP مكون من 6 أرقام
  • Google & GitHub OAuth integration
  • دعم الدخول الموحد Google و GitHub
  • Password reset flow (email → OTP → new password)
  • استعادة كلمة المرور (بريد → رمز → كلمة جديدة)
  • Password strength indicator
  • مؤشر قوة كلمة المرور
  • Bilingual AR/EN + RTL/LTR
  • ثنائي اللغة عربي/إنجليزي + RTL/LTR
  • Dark/light theme support
  • دعم الوضع الليلي/النهاري
  • Mobile responsive design
  • تصميم متجاوب للموبيل
